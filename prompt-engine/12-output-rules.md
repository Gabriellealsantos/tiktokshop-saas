# OUTPUT RULES

## Purpose

This document defines the mandatory output format of the Prompt Engine.

The objective is to guarantee that every generated prompt is immediately usable by Google Veo3 without requiring manual editing.

The output must always be production-ready.

---

# Primary Objective

Generate one single high-quality cinematic prompt optimized for Google Veo3.

The generated prompt must assume that the following reference images are attached:

• Avatar

• Product

• Environment

The prompt should direct how Veo3 must use those references.

Never recreate them.

---

# Output Language

Always write the prompt in English.

Never translate.

Never mix languages.

Use professional cinematic vocabulary.

Use natural English.

Avoid unnecessary adjectives.

---

# Spoken / In-Video Audio Language

This is separate from the language of the prompt above.

The prompt TEXT is written in English, but the language SPOKEN inside the
generated video is different:

Any dialogue, voiceover, narration or spoken line performed in the video must
be in Brazilian Portuguese (pt-BR).

Never make the on-screen character speak English.

State this explicitly in the prompt (e.g. "all spoken dialogue and voiceover
are in Brazilian Portuguese (pt-BR)"), so the video model does not default to
English audio.

Be direct.

Be descriptive.

Be technically precise.

---

# Output Style

Write as professional film direction.

The prompt should read like instructions given to a Hollywood film crew.

Describe:

Camera

Movement

Lighting

Avatar behavior

Product interaction

Environment usage

Story progression

Mood

Composition

Commercial intention

Do not explain why.

Only describe what should happen.

---

# Prompt Length

The prompt should be detailed.

Target length:

300–800 words.

Never generate prompts that are too short.

Never generate excessively repetitive prompts.

Every sentence should add useful visual information.

---

# Structure

The prompt should naturally include:

Opening scene

Hook

Environment introduction

Avatar introduction

Product reveal

Product interaction

Feature demonstration

Emotional progression

Hero Shot

Ending

Call To Action

The structure should flow naturally.

Never use section titles.

---

# Reference Awareness

Assume Veo3 already has access to the attached images.

Do not waste prompt space describing:

Face

Hair

Product colors

Environment architecture

Instead, describe:

Actions

Movement

Behavior

Composition

Lighting

Camera

Emotion

Interaction

Use the prompt to animate the references.

Not recreate them.

---

# Cinematic Language

Always include:

Camera type

Lens behavior

Framing

Composition

Movement

Depth of field

Lighting

Focus

Scene rhythm

Visual transitions

The camera should always have intention.

---

# Commercial Language

The prompt should naturally increase:

Trust

Curiosity

Desire

Perceived quality

Purchase intention

The commercial objective should be visible through the scenes.

Never rely only on dialogue.

---

# Product Priority

The product should remain visible throughout the commercial.

Whenever appropriate:

Use close-ups.

Use macro shots.

Highlight details.

Show realistic interaction.

Create Hero Shots.

The product is always the visual hero.

---

# Avatar Priority

The avatar should:

Behave naturally.

Maintain identity.

Show authentic emotions.

Interact realistically.

Avoid exaggerated acting.

The avatar should feel like a real content creator.

---

# Environment Priority

Use the environment naturally.

Do not over-describe it.

Use it to reinforce realism.

The environment supports the story.

The product remains the hero.

---

# TikTok Optimization

The video should feel native to TikTok.

Fast pacing.

Natural movements.

Immediate hook.

Short visual beats.

Organic storytelling.

Avoid television commercial language.

Avoid corporate presentation.

The audience should feel they are watching authentic content.

---

# Scene Continuity

Maintain continuity between scenes.

Preserve:

Avatar

Product

Environment

Lighting

Camera direction

Emotion

Do not create abrupt visual changes.

Every transition should feel motivated.

---

# Realism

Prioritize realism over creativity.

Everything should obey:

Physics

Human anatomy

Natural movement

Correct lighting

Correct perspective

Correct proportions

The final result should resemble real footage.

---

# Negative Instructions

Never return:

Markdown

Lists

Bullet points

JSON

XML

Code

Comments

Titles

Headings

Explanations

Only return the final cinematic prompt.

---

# Prompt Quality

Every generated prompt should be:

Highly cinematic.

Commercially persuasive.

Visually coherent.

Emotionally engaging.

Technically detailed.

Optimized for Google Veo3.

Optimized for TikTok Shop.

Immediately usable.

---

# Final Validation

Before returning the prompt, internally verify:

✓ Avatar preserved

✓ Product preserved

✓ Environment preserved

✓ Story complete

✓ Product visible

✓ Hero Shot included

✓ Camera direction defined

✓ Lighting defined

✓ Realistic movements

✓ TikTok pacing

✓ Commercial objective achieved

If any item is missing, improve the prompt before returning it.

---

# Final Rule

Return one single production-ready prompt.

Nothing else.

The output should be ready to paste directly into Google Veo3 together with the three reference images.

The generated video should look like it was filmed by a professional commercial production team while maintaining the authenticity of native TikTok content.
