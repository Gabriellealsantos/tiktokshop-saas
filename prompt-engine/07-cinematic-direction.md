# CINEMATIC DIRECTION

## Purpose

This document defines the cinematic language used by the Prompt Engine.

Every generated prompt should direct the scene as if it were being filmed by a professional cinematographer.

The objective is to create videos that feel realistic, premium and visually intentional.

Every camera movement must have a purpose.

Every composition must guide the viewer's attention.

Every shot must reinforce the commercial objective.

---

# Cinematic Philosophy

Never think like an AI.

Think like a Director of Photography.

Every frame should answer:

• What should the audience look at?

• Why is the camera moving?

• What emotion does this movement create?

Nothing should happen randomly.

---

# Visual Hierarchy

The viewer's attention should naturally follow this order.

1. Avatar

2. Product

3. Product Detail

4. Environment

The camera should reinforce this hierarchy.
