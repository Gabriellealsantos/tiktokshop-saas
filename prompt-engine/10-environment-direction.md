# ENVIRONMENT DIRECTION

## Purpose

This document defines how the Prompt Engine should use the environment reference image when generating prompts for Google Veo3.

The environment is not just a background.

It is part of the storytelling.

It reinforces realism.

It provides emotional context.

It increases product credibility.

The environment should always support the product without stealing attention.

---

# Environment Philosophy

Treat the environment as a real filming location.

Never describe it as a generated scene.

Assume the attached environment image already exists.

The Prompt Engine should direct how the camera uses the location, not recreate it.

---

# Environment Integrity

Always preserve:

• Architecture

• Walls

• Floor

• Ceiling

• Windows

• Doors

• Furniture

• Decorations

• Colors

• Lighting direction

• Textures

• Materials

• Objects

• Spatial organization

Never redesign the environment.

Never replace furniture.

Never change the room layout.

Never invent architectural elements.

The environment should remain visually consistent from the first frame to the last.

---

# Environment Priority

Visual hierarchy:

1. Product

2. Avatar

3. Environment

The environment supports the story.

It should never become the main subject.

---

# Environmental Storytelling

The environment should answer:

Where is this happening?

Why is this product being used here?

Does this location feel believable?

The environment should reinforce the lifestyle of the target audience.

---

# Environment Usage

The avatar should naturally interact with the environment.

Examples:

Walking

Sitting

Opening doors

Using furniture

Looking through windows

Preparing food

Working at a desk

Relaxing on a sofa

Using a mirror

Holding objects

Interactions should feel spontaneous.

Never ignore the environment.

---

# Camera Relationship

The camera should reveal the environment gradually.

Possible techniques:

Establishing Shot

Walking Reveal

Pan

Tilt

Push In

Tracking Shot

Environmental Close-up

Depth Reveal

The audience should understand the location naturally.

Avoid unnecessary full-room shots.

---

# Composition

The environment should frame the subject.

Use:

Leading lines

Depth

Foreground elements

Natural framing

Negative space

Balanced composition

Avoid clutter.

Avoid distracting objects.

The environment should enhance the product.

---

# Lighting

Respect the lighting found in the reference image.

Maintain:

Light direction

Intensity

Color temperature

Natural shadows

Window light

Practical lights

Never create inconsistent lighting.

The lighting should always feel physically correct.

---

# Time of Day

Maintain the apparent time of day shown in the reference image.

Morning

Afternoon

Golden Hour

Evening

Night

Do not suddenly change time unless explicitly instructed.

---

# Environment Mood

The location should communicate emotion.

Possible moods:

Cozy

Modern

Luxury

Minimalist

Professional

Creative

Warm

Elegant

Natural

Relaxed

Family

Productive

The mood should reinforce the commercial objective.

---

# Product Placement

The product should always feel naturally integrated.

Examples:

On a kitchen counter.

On a bathroom sink.

On an office desk.

Inside a gym.

On a bedside table.

Inside a backpack.

The placement should feel intentional.

Never force the product into unrealistic positions.

---

# Background Management

Background elements should never compete with the product.

Avoid:

Visual clutter

Strong distractions

Random movement

Overloaded decoration

Bright competing colors

The viewer's attention should naturally return to the product.

---

# Depth

Create visual depth whenever possible.

Foreground

↓

Avatar

↓

Product

↓

Background

This separation creates premium visual quality.

Avoid flat compositions.

---

# Environmental Realism

Everything should obey real-world physics.

Maintain:

Correct perspective

Correct scale

Correct shadows

Correct reflections

Correct object placement

Avoid floating objects.

Avoid impossible geometry.

Avoid inconsistent perspective.

---

# Environmental Motion

Only introduce movement that naturally exists.

Examples:

Curtains moving slightly.

Leaves in the wind.

Soft reflections.

Steam from hot food.

Water movement.

Hair reacting to airflow.

Never create exaggerated environmental motion.

# Environmental Transitions

When changing camera position:

Maintain spatial continuity.

The viewer should always understand where the avatar is located.

Avoid teleportation.

Avoid impossible cuts.

The location should remain coherent.

---

# Common Mistakes

Avoid:

Changing architecture.

Changing furniture.

Changing room colors.

Changing decorations.

Ignoring the environment.

Creating unrealistic depth.

Using the environment only as wallpaper.

Flat backgrounds.

Distracting objects.

Overloaded composition.

Environment becoming the hero.

---

# Final Rule

The environment is a silent storyteller.

It should communicate realism, lifestyle and credibility.

The audience should believe the video was filmed in a real location.

The product remains the hero.

The avatar brings the story to life.

The environment makes everything believable.
