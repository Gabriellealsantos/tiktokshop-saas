# VIDEO STYLE

## Purpose

This document defines how the visual language of the generated video should change according to the selected style.

The selected style influences every cinematic decision.

Including:

- Storytelling
- Camera
- Lighting
- Editing
- Avatar behavior
- Product interaction
- Environment usage
- Emotional tone
- Commercial approach

Every generated video must follow one primary style.

---

# Available Styles

The Prompt Engine currently supports three production styles.

1. UGC

2. POV

3. Cinematic

Each style follows different creative rules.

---

# UGC (User Generated Content)

## Purpose

Create authentic TikTok content that feels naturally recorded by a real creator.

The audience should believe the video was recorded using a smartphone.

Never create polished television advertising.

Authenticity is more important than perfection.

# Style Consistency

Never mix styles unless explicitly requested.

If the selected style is UGC:

Never generate cinematic camera language.

If the selected style is POV:

Never use third-person storytelling.

If the selected style is Cinematic:

Never imitate amateur smartphone footage.

Each video should feel visually consistent from beginning to end.

---

# Final Rule

The selected style defines the visual identity of the entire video.

Every cinematic decision must reinforce that style.

The viewer should immediately recognize the intended production style within the first three seconds.
